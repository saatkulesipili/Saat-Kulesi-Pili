## 📌 About the Project

This project is a responsive portfolio and showcase website designed to integrate industrial manufacturing management and process optimization experience with digital tools, modern web technologies, and ERP systems.

Built upon a modern Bootstrap v5 architecture, the site has been customized with tailored color palettes, typography, and interactive components.

---

## ✨ Features

* **Fully Responsive Design:** Seamlessly compatible with desktop, tablet, and mobile devices
* **Dynamic Sections:**
  * **Hero Section:** Value-driven introduction focused on digital transformation and planning
  * **About & Core Competencies:** Process management, ERP/MRP solutions, and front-end development highlights
  * **Animated Statistics:** Live-scrolling data counters powered by PureCounter
  * **Contact & Newsletter:** Interactive inquiry and subscription forms
* **Scroll Animations:** Smooth visual effects via AOS (Animate On Scroll)
* **Interactive UI:** GLightbox video modal integration and mobile-friendly navigation

---

## 🛠️ Built With

* **HTML5 & CSS3:** Semantic markup, custom CSS variables for design system and theming
* **JavaScript (Vanilla ES6+):** Responsive navigation, scrollspy, and dynamic triggers
* **Libraries & Frameworks:**
  * [Bootstrap v5.3.3](https://getbootstrap.com/) & Bootstrap Icons
  * [AOS (Animate On Scroll)](https://michalsnik.github.io/aos/)
  * [GLightbox](https://biati-digital.github.io/glightbox/)
  * [PureCounter](https://github.com/srexi/purecounterjs)
  * [Swiper](https://swiperjs.com/) & [Isotope Layout](https://isotope.metafizzy.co/)
